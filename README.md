# TechLead app (v1)

Live app: https://claude.ai/artifact/Qp92u2Vpg3fwkKDcpGDJga (private to Affes)

## What it tracks
- **Solutions**: name, purpose, health (on track / at risk / off track), phase (Discovery to Sunset).
- **Tasks**: board with To do / In progress / Blocked / Done, linked to a solution and an owner, with priority and due date.
- **Decisions**: numbered architecture decision records (ADR-001...) with context, decision, consequences and status (proposed / accepted / superseded / rejected).
- **Team**: each person's role, solutions, status (on track / overloaded / blocked / away) and a status note.
- **Overview**: a "needs your attention" strip (blocked, overdue, pending decisions, people needing support) and one card per solution.
- A solution filter in the header scopes every view.

## Stack
- One HTML file, plain JavaScript, no build step.
- Hosted as a claude.ai artifact; data lives in the artifact's built-in database (collections `solutions`, `tasks`, `decisions`, `people`), so it persists across devices and Claude can read or bulk-load it.
- Source: `index.html` in this folder. Republish from it to update the same link.
